Sources : s1 Call of Duty League, About The Call of Duty League (callofdutyleague.com, site officiel de la ligue d'Activision) ; s2 Call of Duty League, 2026 Season Announcement (callofdutyleague.com, 28 octobre 2025) ; s3 Call of Duty League, 2027 Season Announcement (callofdutyleague.com, 14 octobre 2026) ; s4 Call of Duty: Black Ops 7 sur Steam (store.steampowered.com, fiche rédigée par l'éditeur Activision). Vérifié le 2026-10-27.

Les pages s1, s2 et s3 de callofdutyleague.com sont affichées par JavaScript : elles répondent bien 200, mais le texte n'est pas dans le HTML visible (il est dans les données du script), un script ne peut donc pas y retrouver d'extrait. Leurs lignes sont « manuel » : le texte a été lu dans un navigateur le 2026-10-27 et l'extrait anglais est recopié dans la raison. Le site callofduty.com d'Activision ne répond pas à un script (délai dépassé) : il n'est pas utilisé. Le nombre d'équipes de la ligue n'est pas donné (il change : M80 Boston arrive en 2027). Les quatre Majors, les points CDL, les Minor et le troisième mode de jeu sont datés (« In recent seasons », « in the 2026 season ») ; le texte renvoie au site officiel pour le format en cours. La taille des équipes (quatre contre quatre) n'est pas donnée : aucune page officielle lisible ne l'indique.
